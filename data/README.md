# Data layout

Raw dataset files are not committed to this repository.

```text
raw/images/          Official PNG images
raw/annotations.csv  Official expert polygons
raw/metadata.csv     Official steel sample metadata
processed/masks/     Generated by MicroPhaseLab
processed/manifest.csv
splits/train.csv
splits/val.csv
splits/test.csv
```

Keep original files read-only. When reprocessing data, create a new `processed`
directory instead of overwriting source images.
