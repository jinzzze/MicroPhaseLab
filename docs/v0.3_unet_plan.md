# v0.3 Minimal Reproducible U-Net Plan

## Goal

Use checked manifests and group-aware splits to teach binary MA segmentation with a
small U-Net. The goal is reproducible training and defensible evaluation, not a claim
of state-of-the-art performance.

## Non-goals

- Do not train directly from unchecked raw images.
- Do not select checkpoints or hyperparameters on the test split.
- Do not require a pretrained real-data model.
- Do not interpret a 2D mask area fraction as a 3D volume fraction.

## Software boundary

PyTorch is optional: install it with pip install -e ".[torch]". The v0.2 downloader,
preparation, quality checks, and classical baseline work without PyTorch. Windows
users should choose an appropriate CPU or CUDA build from the official selector.

## Implemented modules

~~~
src/microphaselab/
├── torch_dataset.py   # Reads manifests and returns 1×H×W tensors
├── unet.py            # Compact single-channel U-Net
├── training.py        # Seeds, training, validation, and checkpoints
└── inference.py       # Checkpoint prediction, evaluation, and comparison figures
~~~

The train, predict, and evaluate commands are implemented.

## Data contract

1. Train reads train.csv, validation reads val.csv, and final reporting reads test.csv.
2. Every CSV retains image_id, group_id, image_path, and mask_path.
3. Images are grayscale float32 tensors with shape 1×H×W; masks are float32 0/1 tensors.
4. Resize, normalization, random seed, and other run settings are written to the run configuration.
5. Training rejects any group_id shared by two supplied splits.

## Model and training

- A four-level U-Net takes one grayscale channel and returns one logit channel.
- The loss is BCEWithLogitsLoss plus Dice loss.
- Validation reports Dice, IoU, precision, recall, and MA area-fraction absolute error.
- The default configuration can run on CPU; CUDA is optional.
- best.pt stores the best validation-Dice state, configuration, and epoch.

## Commands and outputs

~~~powershell
microphaselab train --config configs/unet_demo.yaml
microphaselab predict --checkpoint outputs/unet/run_001/best.pt --manifest data/splits/test.csv
microphaselab evaluate --manifest data/splits/test.csv --predictions outputs/unet/run_001/predictions
~~~

Inference writes prediction_manifest.csv. Evaluation writes metrics_per_image.csv and
summary.json, and can generate expert/prediction/error comparison figures.

## Acceptance criteria

1. Dataset tests cover grayscale tensors, binary masks, missing files, and dimension validation.
2. The model maps a 1×1×128×128 input to same-sized logits.
3. A CPU smoke test writes a checkpoint and training metrics from an offline fixture.
4. A group-leakage test fails before training.
5. An end-to-end test runs training, prediction, evaluation, and comparison figures.
6. A real-data report records commit, configuration, split, seed, metrics, visual QC, and limitations.
