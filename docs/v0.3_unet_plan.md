# v0.3：最小可复现 U-Net 计划

## 目标

在不破坏 v0.2 轻量、CPU 可运行数据管线的前提下，让学生从已检查的
manifest.csv 和 group-aware splits 训练一个二值 MA segmentation 模型。
v0.3 的目标是理解可复现训练和正确评估，不是追求论文级最高分。

## 非目标

- 不把未检查的官方原始图像直接送入训练；
- 不在 test 集上调超参数或选择 checkpoint；
- 不发布“真实数据预训练权重”作为 v0.3 的前置条件；
- 不将二维 mask 的面积分数直接解释为三维体积分数。

## 软件边界

PyTorch 应作为可选依赖，例如 pip install -e ".[torch]"；v0.2 的下载、
准备、质量检查和传统基线不得依赖 PyTorch。Windows 安装说明应链接到 PyTorch 官方
安装选择器，以匹配学生的 CPU、CUDA 与 Python 组合。

建议新增模块：

~~~
src/microphaselab/
├── torch_dataset.py   # 从 manifest 读取 image/mask，验证尺寸，返回 1×H×W tensor
├── unet.py            # 小型单通道 U-Net 和可测试的 forward
├── training.py        # 种子、训练循环、验证、checkpoint、指标汇总
└── inference.py       # checkpoint 推理与预测 mask 输出
~~~

## 固定的数据契约

1. 训练只读取 data/splits/train.csv，验证只读取 val.csv，最终报告只读取 test.csv。
2. 每个 CSV 必须保留 image_id、group_id、image_path 和 mask_path。
3. 图像读为灰度并显式转换成 float32、形状 1×H×W；mask 读为 float32 的 0/1。
4. resize、归一化、随机增强与随机种子必须写入一次运行的配置文件。
5. 训练开始前检查 train/val/test 的 group_id 交集为空；不满足时立即报错。

## 最小模型与训练

- 模型：4 个下采样层、单通道输入、单通道 logits 输出的小型 U-Net。
- 损失：BCEWithLogitsLoss + Dice loss，并分别记录两项。
- 验证指标：Dice、IoU、Precision、Recall、MA 面积分数绝对误差。
- 默认配置：CPU 可运行的小尺寸输入、小 batch、固定 seed=42；GPU 只作为加速选项。
- checkpoint：只保存验证 Dice 最好的权重，同时保存模型参数、训练配置、epoch 和随机种子。

## 命令行与产物

建议提供三个命令：

~~~powershell
microphaselab train --config configs/unet_demo.yaml
microphaselab predict --checkpoint outputs/unet/run_001/best.pt --manifest data/splits/test.csv
microphaselab evaluate --manifest data/splits/test.csv --predictions outputs/unet/run_001/predictions
~~~

一次训练应产生：

~~~text
outputs/unet/<run_id>/
├── config.yaml
├── metrics.csv
├── best.pt
├── validation_summary.json
└── predictions/
~~~

## 分阶段验收

1. **Dataset 单元测试**：灰度维度、0/1 mask、尺寸不匹配与缺失文件都得到明确处理。
2. **Model 单元测试**：随机 1×1×128×128 输入返回同尺寸 logits。
3. **Smoke test**：在离线 demo 上用 CPU 训练极少 epoch，能写出 checkpoint 和指标文件。
4. **泄漏测试**：故意重叠 group 时训练必须失败。
5. **真实数据实验**：只使用 validation 调参；冻结参数后只运行一次 test，并报告配置、
   随机种子、每图指标与局限性。

完成前四项才合并 v0.3 代码；第五项是课程实验报告，而非安装测试。
